## 📌 Overview

Welcome to **Solving C**! This module serves as a personal learning journal and lab practice archive for the **Advanced Algorithm** course (**Course Code: CSE 2201**). It is designed to reinforce core C programming principles, deep dive into foundational and advanced data structures, and sharpen algorithmic problem-solving skills.

Every solution is organized into independent `.c` files, making it easy to practice, test, and understand key programming concepts step-by-step.

---

## 🎯 Curriculum & Focus Areas

- 🔢 **Core Fundamentals & Memory** — Pointers, dynamic memory allocation (`malloc`, `calloc`, `realloc`, `free`), structs, bitwise operations, and file I/O.
- 🧱 **Data Structures** — Arrays, singly & doubly linked lists, stacks, queues, circular buffers, binary trees, BST, heaps, and graphs.
- ⚡ **Sorting Algorithms** — Bubble, Selection, Insertion, Merge, Quick, Heap, and Counting Sort.
- 🔍 **Searching Algorithms** — Linear Search, Binary Search, and variants.
- 🔁 **Recursion & Backtracking** — N-Queens, Maze Solving, Subset Generation, and Permutations.
- 📐 **Dynamic Programming & Greedy** — Memoization, Tabulation, 0/1 & Fractional Knapsack, Longest Common Subsequence (LCS), and Activity Selection.
- 🌐 **Graph Algorithms** — BFS, DFS, Dijkstra, Bellman-Ford, Prim, and Kruskal.
- 🧠 **Lab Tasks & Coursework** — Academic coursework, algorithm complexity analysis, and competitive problem-solving.

## 💻 Execution Guide

Ensure you have a C compiler installed (e.g., [GCC via MinGW](https://www.mingw-w64.org/) on Windows or `build-essential` on Linux).

### 1. Compile and Run via Terminal

```yaml
# Step 1: Compile source file
gcc filename.c -o output

# Step 2: Run executable (Linux / macOS)
./output

# Step 2: Run executable (Windows)
output.exe
```

### 2. One-Liner Compilation & Execution

```yaml
# Compile and immediately run if compilation succeeds
gcc filename.c -o output && ./output

# Recommended: Enable all compiler warnings for robust code
gcc -Wall -Wextra -O2 filename.c -o output && ./output
```
